# GameGenetics

Pet Shop Mendel é um protótipo de genética mendeliana no navegador. O esboço do nível 1, os sprites e como a conta do Punnett funciona estão em `ESBOCO.md`.

```bash
python3 -m http.server 8765
```

Abra `http://localhost:8765`. Os testes da lógica monoíbrida rodam com `node tests/genetics.test.js`.
