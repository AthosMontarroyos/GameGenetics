30 character variants generated with the built-in image_gen tool.
Every generation used only the corresponding original brown base PNG as input.
Each delivered PNG is 1024x1024 and uses a solid #FF00FF magenta background.
prompts.json contains every generation prompt and base path.
generated-sources.json records the original generated files.
validation.csv records export dimensions and silhouette comparison against the base.

ALIGNMENT LIMITATION
Generative image editing preserved framing closely but did not preserve every pixel.
Even upright recolor variants have small differences along their silhouettes and in
their internal rendering. These files are not certified pixel-identical overlays.
Ear and tail variants also intentionally change the silhouette of those features.
